# How much of this is yours?

A projected memory loop. Photographs by Jason Lindsey.

## Publish on GitHub Pages
1. Create a new repository and upload everything in this folder (keep `index.html` at the top level, next to the `assets` folder).
2. In the repository: Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
3. After a minute the piece is live at `https://<your-username>.github.io/<repository-name>/`.

## Viewing locally
The page loads its images with `fetch`, so opening `index.html` by double-clicking won't work. From this folder run
`python3 -m http.server` and open http://localhost:8000.

## Keys
Click the writing to read it, click again or Esc to step back, click elsewhere to move on.
N next frame · [ ] speed · Z flash · X flashes on/off · S sound · − + volume · G grain · I timecode · F fullscreen
